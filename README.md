
# Student Management System

## Project Details
- Project Name: Student Management System
- Language: C Programming
- Course: B.Tech CSE-AIML
- Semester: First Semester
- University: AKS University, Satna

## Introduction
This project is a console-based Student Management System developed using C programming.

It helps users manage student records easily.

## Features
1. Add Student
2. Display Students
3. Search Student
4. Update Student
5. Delete Student
6. Save Records using File Handling

## Concepts Used
- Structures
- Functions
- Loops
- Switch Case
- Conditional Statements
- File Handling

## How to Run
1. Download the source code.
2. Open it in a C compiler.
3. Compile the program.
4. Run the program.

## Conclusion
This project helps us understand the basic concepts of C programming.
